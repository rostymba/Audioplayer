# Audioplayer

Личное демо EPUB-читалки с атмосферным интернет-радио. Книги остаются в браузере, профиль атмосферы определяется локально, а станции подбираются через открытый каталог Radio Browser.

## Что уже работает

- загрузка EPUB до 75 МБ;
- локальная библиотека и сохранение прогресса в IndexedDB;
- чтение через EPUB.js;
- локальный анализ атмосферы текста на русском и английском;
- автоматический поиск радиостанций по атмосферным тегам;
- play/pause, громкость, смена неподходящей станции и ICY-метаданные;
- история музыкального сопровождения в скрываемой левой панели;
- плавный 8-секундный переход между двумя потоками, когда браузер и станции это позволяют.

## Запуск

Нужен Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000), загрузите `.epub` и разрешите воспроизведение звука, если браузер остановит автозапуск.

Проверки перед сборкой:

```bash
npm run lint
npm run build
npm audit
```

## Границы первой версии

Это локальное некоммерческое демо без регистрации и серверной библиотеки. Радио зависит от доступности внешних потоков; отдельные станции могут не поддерживать браузерное воспроизведение, метаданные или одновременное подключение для crossfade. Анализ атмосферы пока эвристический — архитектура допускает замену на AI-анализатор.

Подробное продуктовое и техническое описание: [docs/audioplayer-spec.md](docs/audioplayer-spec.md).

## Международное сопровождение книги

Каталог встроен в подбор сопровождения: отдельных экранов выбора радио нет. Radio Browser запрашивается страницами по 250 записей на жанровый тег, остальные страницы подгружаются в фоне. Лимит в 24 потока снят. Одинаковые адреса и варианты кодека одной станции объединяются; страны чередуются в очереди. Страна означает страну станции в каталоге, а не происхождение исполнителя.

После четырёх минут воспроизведения система выбирает ещё не посещённую станцию, предпочитая другую страну. Подбор пока основан на жанрах книги, а не на анализе звучания текущей композиции. Метаданные треков записываются в историю. Неудачный переход сохраняет работающий эфир. При отсутствии других источников текущая станция остаётся выбранной.

Историю можно скачать в JSON: успешные подключения и завершённые переходы содержат stationId, URL потока, страну, время и причину. Смена названия трека внутри станции записывается отдельно и не считается переключением источника.

## Проверка радио

`npm test` собирает приложение и запускает его на порту 3001. Нужен установленный Google Chrome. Тесты загружают настоящий минимальный EPUB и подставляют контролируемые WAV-потоки; проверяют воспроизведение трёх разных URL, остановку старого канала, автоматическую ротацию, удаление дублей и отказ следующего потока. Эти тесты не доказывают доступность внешнего радио.

`npm run test:radio-live` при работающем приложении на порту 3000 проверяет настоящие потоки разных стран в Chrome: успешным считается запуск аудио с продвижением времени. Требуется не менее трёх разных стран; выводится JSON-отчёт. Проверка зависит от сети и доступности станций. Адрес приложения можно переопределить переменной `RADIO_TEST_URL`.

Дополнительные каталоги пока не подключены: проверенный XML-экспорт Icecast возвращал HTTP 404. Зеркала Radio Browser являются резервными серверами одной базы, а не независимыми каталогами.
